# AVL-Tree


**AVL Tree with its self-balancing functionalities**

JAVA program demonstrating the working of an AVL Tree (self - balancing tree), with insertion, deletion and traversal fucntionalities.

Insertion at the beginning, end and at a given position.

Deletion at the beginning, end and at a given position.

Inorder traversal throughout.

Automatic balancing (LL, RR, LR, RL rotations); for both insertion and deletion.

Balance factor calculation for each node (root displayed).

Height updation after each operation.

(# Duplicate nodes are prevented and thus not included separately.)
